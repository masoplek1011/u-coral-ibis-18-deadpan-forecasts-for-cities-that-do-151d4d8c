A single deadpan weather forecast for Veltria, a city that does not exist — rain confined to one 40-metre stretch of cobblestone, 2.1 millimetres, all afternoon. Elsewhere, dry.

[Bounty on make.fun](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c)

## Run

```sh
npx tsc main.ts --module nodenext --target es2022 --outDir dist
MAKEFUN_OUTPUT_DIR=./out node dist/main.js
```

Writes `entry.txt` (one line, UTF-8) into `$MAKEFUN_OUTPUT_DIR`.
